# A Physicist's Perspective

আমার ছাত্রদের জন্য বানানো একটি ওয়েবসাইট — লেকচার, টাইমড MCQ পরীক্ষা আর ফ্লিপ-কার্ড প্র্যাকটিস, সব এক জায়গায়।

**Live site:** https://meskat00.github.io/a-physicists-perspective/

SSC, HSC আর Admission — তিন স্তরের শিক্ষার্থীদের জন্যই এখানে কনটেন্ট আছে। পদার্থবিজ্ঞান আর উচ্চতর গণিতের প্রতিটি অধ্যায় ধরে সাজানো: ভিডিও লেকচার, অধ্যায়ভিত্তিক পরীক্ষা, আর বোর্ড ও ভর্তি পরীক্ষার আসল প্রশ্নের সেট।

সাইটটি সাধারণ HTML, CSS আর JavaScript দিয়ে বানানো, GitHub Pages-এ হোস্ট করা।
